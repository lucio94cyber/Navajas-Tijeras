# 💈 NAVAJAS Y TIJERAS
### Barbería | Estilo y personalidad

Una propuesta digital para barberías que buscan mostrar sus servicios, transmitir su identidad y conectar con nuevos clientes.

## 🌐 Proyecto web

[**Explorar Proyecto →**](https://navajasytijeras.netlify.app/)

## ✨ Características

- Presentación de la barbería.
- Exhibición de servicios.
- Identidad visual moderna.
- Diseño pensado para el rubro.
- Adaptación a dispositivos móviles.

## 🎯 Objetivo del proyecto

Crear una presencia online que permita mostrar la identidad de la barbería y facilitar el acercamiento de potenciales clientes.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JS

## 📂 Sobre este repositorio

Demo de sitio web institucional para barbería, desarrollada con foco en la identidad visual y la experiencia del usuario.
